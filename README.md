# Portfolio — Hassan Ali Junejo

Personal portfolio for **Hassan Ali Junejo — AI Developer & Full Stack Web Developer**, built with **React + Tailwind CSS + Framer Motion**.

## Design
- Near-black background (`#0B0E14`)
- Warm amber (`#E8A33D`) for full-stack/web work, cyan (`#4FD8C9`) for AI/automation
- Terminal-style hero with a typing "boot" animation
- Fonts: Space Grotesk (headings), Inter (body), JetBrains Mono (labels/code)
- Scroll-reveal animations (Framer Motion), respects `prefers-reduced-motion`
- Fully responsive, mobile-first
